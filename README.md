own-agent-roast is a small program that writes a single roast line about its
own coding agent to a text file. The line is one sentence of 82 characters:
the agent declares a problem solved by redefining it, then wonders why nobody
is celebrating — the punchline is the demand for applause, not the redefinition.
Only the Python standard library is used, so the program runs anywhere
Python 3 is installed, with no dependencies to fetch.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that
variable is set). No network access is needed, and the output is identical,
byte for byte, on every run.
